Analysis pipeline for the UbiLife mobile sensing dataset collected during UbiComp 2025 in Helsinki, Finland.

## About

This project analyzes mobile sensing data from the UbiLife dataset collected during a week-long conference with ~82 participants (Oct 9-29, 2025). The dataset includes 15 data streams (location, step count, activity, surveys, weather, and more) with over 1 million records.

**Data types available:**
- Passive sensors: location, step count, activity recognition, ambient light, heart rate
- Active data: surveys (onboarding, daily stress/sleep, WHO-5, BFI-10, session ratings)
- Device data: battery state, device information, screen events
- Environmental: weather, air quality

## Getting Started

### Prerequisites

- Python 3.10+
- [uv](https://github.com/astral-sh/uv) (recommended) or pip

### Setup

Using uv (recommended):
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync
```

Using pip:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

### Data

Place the UbiLife dataset files in `data/raw/`. The raw data is not tracked in git due to its size (~587 MB).

The processed dataset is tracked in `data/processed/` and ready to use. To regenerate it from raw data, run notebook `02_data_preparation.ipynb`.

### Raw Data

The raw JSON is converted to 15 parquet files in `data/raw/parquet/` via `CarpDataStream.convert_to_parquet()`. All records span Oct 9–29, 2025 across 82 participants.

| Stream | Records | Features |
|---|---|---|
| `activity` | 199k | `type` (STILL, WALKING, IN_VEHICLE, ON_BICYCLE, RUNNING), `confidence` |
| `location` | 133k | `latitude`, `longitude`, `altitude`, `speed`, `heading`, `accuracy` |
| `stepcount` | 448k | `steps` (cumulative pedometer counter) |
| `heartbeat` | 205k | `period`, `deviceType`, `deviceRoleName` |
| `batterystate` | 18k | `batteryLevel`, `batteryStatus` |
| `weather` | 3.9k | `temperature`, `tempMin/Max`, `humidity`, `pressure`, `windSpeed`, `windDegree`, `cloudiness`, `rainLastHour`, `weatherMain`, `weatherDescription`, `sunrise/sunset` |
| `airquality` | 3.8k | `airQualityIndex`, `airQualityLevel`, `source`, `latitude/longitude` |
| `ambientlight` | 3.1k | `meanLux`, `minLux`, `maxLux`, `stdLux` |
| `screenevent` | 5.7k | `screenEvent` (SCREEN_ON, SCREEN_OFF, SCREEN_UNLOCKED) |
| `survey` | 765 | Nested survey responses (18 survey types, see processed tables below) |
| `triggeredtask` | 12k | Task trigger metadata |
| `completedapptask` | 708 | Completed task data (cognition tests, surveys) |
| `deviceinformation` | 211 | `platform`, `deviceManufacturer`, `hardware`, `deviceModel`, `operatingSystem` |
| `image` | 18 | Image capture metadata |
| `error` | 341 | Error logs |

All streams share common metadata: `participant_id` (`dataStream.studyDeploymentId`), `timestamp` (`measurement.sensorStartTime` in microseconds).
